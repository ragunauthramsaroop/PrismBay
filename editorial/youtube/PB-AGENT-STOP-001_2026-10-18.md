## Audience problem
Founders and operations leaders deploy agents with tool access but confuse an instruction to stop with technical revocation of permissions. This episode teaches one concrete acceptance test before production.

## Script (~137 words, target ~58-65s at natural pace)
[0:00-0:03] "Your AI agent has a stop button. Does the button actually stop anything?"
[0:03-0:12] "Suppose an agent is working through a supplier inbox. You click stop. But its login token still works, and its network connection stays open."
[0:12-0:18] "The screen says stopped. The system still has authority."
[0:18-0:40] "Before deployment, run this three-part kill-switch test. One: stop the job and verify no more tool calls execute. Two: revoke the agent's credentials, then confirm a fresh request fails. Three: block outbound access and inspect the logs for activity after shutdown."
[0:40-0:53] "For risky workflows, also require human approval before payments, deletion, publishing, or changes to access rights. An instruction inside a prompt is not an access control."
[0:53-1:02] "If your team cannot demonstrate all three checks, the agent is not ready for production. PrismBay AI covers practical AI systems with measurable controls."

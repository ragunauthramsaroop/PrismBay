## Core episode
Title: The AI Agent Permission Budget: 5 Controls Before Deployment

An AI support agent is useful when connected systems enforce clear limits. A prompt asking for safe behavior does not replace application-level authorization. Teach five controls through an original fictional support workflow.

1. Identity: assign a distinct service identity, named owner, approved data, and credential expiry.
2. Authority: distinguish Observe, Prepare, Limited Action, and Consequential Action. Keep refunds, deletions, data export, and mass communications behind separate authorization.
3. Scope: restrict destinations, batch size, rate limits, and operating time.
4. Testing: treat external tickets and attachments as untrusted inputs. Test both model behavior and actual tool enforcement.
5. Audit: log actions and approvals, assign an emergency-stop owner, and define incident escalation.

Hypothetical arithmetic: 300 tickets each saving 2 minutes = 10 staff hours released per week. Do not claim cash savings without financial evidence. Evaluate quality, safety, and value independently.

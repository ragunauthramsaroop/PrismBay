## Narration, original
1. A prompt is not a permission system. Telling an AI agent to ask first does not remove its access to the send button.
2. Suppose an agent drafts an email to a supplier. Drafting is useful. Sending creates an external commitment.
3. In a safer workflow, the model sees approved records. It writes the draft to a review queue. Its tool account has no send permission.
4. A person checks the exact recipient and message. A separate service verifies their approval before delivery.
5. The same principle protects payments, bank changes, exports and deletions. Instructions guide behavior. Technical permissions enforce boundaries.
6. Start with four levels. Observe. Draft. Propose. Execute. Grant execute only to narrow, tested actions.
7. If an agent ignores its instructions, the system should still block unauthorized actions. Follow PrismBay AI for practical business systems.

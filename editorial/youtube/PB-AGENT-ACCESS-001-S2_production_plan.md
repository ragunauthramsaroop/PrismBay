## Narration, approximately 119 words
"An AI prompt is not a security boundary. Watch this. An agent reads a supplier email and drafts a reply. The prompt says, 'Do not send messages without approval.' But the agent still has access to the Send tool. A malicious attachment tells it to send the file to a new address. If the tool accepts the command, the instruction failed. Fix the architecture, not the wording. Give the agent read access and a draft-only queue. Remove its Send permission. A separate approval service checks the reviewer, recipient, attachment, and exact message before dispatch. Now the agent cannot send through the restricted workflow, even when an untrusted document gives an instruction. For practical AI systems with accountable controls, follow PrismBay AI."

## Distinctive visual language
Do not reuse the fixed seven-Short background/layout sequence. This episode has five different scene families:
1. **Invoice detective scene**: bespoke fictional invoice with one altered bank-routing field, zoom/crop to the changed field, red STOP overlay. Never display real vendor details.
2. **Permissions matrix**: four original columns OBSERVE / DRAFT / PROPOSE / EXECUTE; highlight actual allowed actions, not decorative animation.
3. **Workflow swimlane**: buyer / AI agent / approvals service / finance system, with arrows that animate only when a valid transition occurs.
4. **Approval gate**: a separate reviewer identity, signed one-transaction approval, policy check, then log. A prompt confirmation is visually crossed out.
5. **Scorecard and test bench**: original formula animation, then five realistic pass/fail tests including a failed attempt and a corrected permission boundary.
Use simple readable typography, clear visual hierarchy, and captions. No fake dashboard screenshots, fake testimonials, unlicensed brand marks, generic AI-face B-roll, or fabricated case-study claims.

## Source grounding and limits
- OWASP LLM06:2025 Excessive Agency: minimum tools/functions, least privilege, independent approval of high-impact actions. https://github.com/OWASP/www-project-top-10-for-large-language-model-applications/blob/main/2_0_vulns/LLM06_ExcessiveAgency.md
- OWASP Prompt Injection Prevention Cheat Sheet: untrusted retrieved text is data, not authority; validate tool arguments and authorization outside the model. https://github.com/OWASP/CheatSheetSeries/blob/master/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.md
- NIST AI RMF: voluntary governance and risk management guidance. https://www.nist.gov/itl/ai-risk-management-framework
- PrismBay OBSERVE / DRAFT / PROPOSE / EXECUTE is an original explanatory taxonomy, NOT a direct quote from NIST or OWASP.
- All supplier details, amounts, volumes, hours and savings are hypothetical. Never portray the numerical illustration as measured results.

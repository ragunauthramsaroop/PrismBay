# PrismBay Super AI v0.4: specialist workspace
- Research: fixed-host live Wikipedia, Crossref and Europe PMC APIs; timestamped source IDs, links, excerpts and source availability. Coverage is restricted to these indexes. Crossref metadata is not full-text verification. AI synthesis is optional and can be wrong; use the source list to verify claims.
- Vault: AES-GCM 256-bit encryption with PBKDF2-SHA256 (600,000 iterations), random salt and IV, browser-local encrypted storage, search, edit, delete, encrypted backup/restore. No cloud synchronization or automatic retrieval into prompts. A copied note is sent only when the owner chooses to submit it. No passphrase recovery. Browser storage deletion removes the vault; keep backups.
- Agent workforce: explicitly approved read-only Analyst/Critic/Synthesizer stages, maximum three sequential model operations, visible partial results, cancel stops further stages. The existing router may retry a provider within a stage. No external account changes, background execution, or guaranteed provider availability.
- Office studio: real editable DOCX and PPTX via pinned docx and PptxGenJS libraries. Uses title and body, recognizes Markdown headings, splits long slides, generates locally in the browser without sending document content to the server. No independent visual QA, PDF generation or chart authoring yet. v0.4.1 retires the server export endpoint and bundles the Office generator into the client.
- No paid service provisioned. Existing hosting/provider limits apply; free-only routes and user consent remain required.
- Run: npm install; npm test; npm run build. Test suite uses mocks except encryption and Office byte generation. Live API checks and visual inspection are separate acceptance gates.

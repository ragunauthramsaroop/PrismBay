# PrismBay Super AI v0.3
Personal noncommercial Hobby deployment. Anonymous OVHcloud documented route without Authorization, no paid fallback; subject to provider limits (2 RPM per IP/model) and current service availability. https://docs.ovhcloud.com/en/guides/public-cloud/ai-machine-learning/ai-endpoints-virtual-models . No quota circumvention; 429/auth failures suppress additional anonymous requests in the same operation. Optional server-side owner routes require per-provider free-only attestations, provider-enforced free-only accounts, and SUPER_AI_OWNER_TOKEN of at least 32 characters. No central credentials are installed by default. WebLLM version pinned with compact open-weight Qwen model; local execution requires WebGPU, memory, initial large download, and explicit enablement. https://github.com/mlc-ai/web-llm . Local prompts are not transmitted by application; model assets downloaded from external hosts. Cloud prompts sent to selected provider; no confidential data. Health endpoint runs a fixed short anonymous generation and caches results, no user data. No global distributed limiter, no background monitoring. Provider policies and hosting limits apply. No commercial usage or paid provisioning approved. Build: npm install && npm run build. 
Health probe prioritizes Mistral and tests a fallback on non-quota failures; council caps cloud attempts at three. Health probe output is not a full end-to-end chat test.

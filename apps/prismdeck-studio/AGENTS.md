# PrismDeck specialist instructions

This is an isolated presentation-editor app inside PrismBay. Follow the root AGENTS.md and .github/copilot-instructions.md, including branch review, no secret exposure, no paid provisioning, and no deployment without owner authorization.

Preserve PPTX editability. All new layouts must pass core model tests and PowerPoint export inspection before production release. Generated data is illustrative unless sourced and reviewed. Keep output fully local by default; do not quietly send decks to a cloud AI service.

Never modify the PrismBay storefront, ecommerce checkout, supplier or social publishing functions while working on PrismDeck. Any new AI backend needs authentication, abuse controls, budget limits, document privacy controls and separate approval.

PrismBay eBay Local Agent

Free local CJ-to-eBay authorization helper and verified eBay draft filler. No TinyFish, Shopify or paid browser automation.

1. Download

Download agent ZIP

The ZIP is built automatically from the public PrismBay GitHub repository.

2. Install

  1. Unzip the downloaded file.
  2. Open chrome://extensions in Chrome, edge://extensions in Edge, or opera://extensions in Opera.
  3. Enable Developer mode.
  4. Click Load unpacked.
  5. Select the unzipped ebay-prismbay folder containing manifest.json.
  6. Pin PrismBay eBay Agent to the toolbar.

3. Connect eBay to CJ

  1. Be signed in to the eBay account StudysmartzLLC and your CJdropshipping account.
  2. Click the PrismBay eBay Agent icon.
  3. Click Connect StudysmartzLLC to CJ.
  4. The agent verifies the eBay account, opens CJ, navigates the eBay authorization flow and fills the store User ID.
  5. If CJ shows a Store Authorization Agreement checkbox, review and tick it.
  6. When eBay shows CJ's permission screen, review it and click I agree.
  7. The agent then verifies CJ shows the eBay store connected.

The authorization runner expires after 15 minutes and can be stopped at any time from the popup.

4. Fill the verified listing draft

  1. Open eBay's selling/listing page.
  2. Click the PrismBay eBay Agent icon.
  3. Click Fill verified draft.
  4. Review every field eBay shows.
  5. Use eBay's own final List button only when the form is accurate.

The agent never clicks the final List button.

Safety

No password storage. No CJ API key in the extension. No Stripe link on eBay. No supplier order or payment. No payout or banking changes. The final eBay permission consent remains a visible account-owner click. Item-location data comes only from the live PrismBay/CJ control plane.
